源版本 c48664385efe850bece9203451e1939974f7b3da，目标初始提交 b9f01a8，仅 README。保留源项目 MIT 全文及免责声明。扫描器仅使用 Python 标准库，未复制或分发 AKShare、pandas、NumPy、OpenViking；行情授权独立于软件许可。
 
|检查|原实现与新实现|
|---|---|
|证券范围|scanner.is_main_board 只排除 688、8/4 和 300，遗漏 301 等。新规则交叉检查沪深代码、主板元数据和名称；独立风险警示历史仍需验证。|
|涨停|旧版倒推20自然日，跳过周末和请求异常。新规则取此前20个开市日，比较原始收盘与供应商当日涨停价，历史特殊制度依赖该字段。|
|涨幅等|源配置与文档区间相符。量比用当日累计股数除以按已过分钟折算的前5日均量，流通市值用股价乘流通股数。|
|K线与压力|保留近5日 (最高-收盘)/收盘 >3% 排除。新增解释为前20日同口径最高价位于现价上方2%以内即有压力。|
|分时|原实现将各成交价与截止时点单一均价比较，且缺失时保留。新版逐分钟比较收盘与当时累计成交额/股数，要求每个已完成连续竞价分钟均覆盖，容差0.5%。|
|财务|原实现用 >=，缺失可保留，环比实际只看同比为正；CAGR使用所获全部年报。新默认采用用户严格大于阈值、季度环比正、恰隔三年的归母利润端点、年度ROE；同日披露保守推迟一天使用。低基数、非经常损益、财报重述与负基数口径仍需独立核验。|
|技术|原实现比较价格与MA50/150及10日与120日均量，异常可保留。新版以前一交易日结束的完整窗口计算，同口径价格比较。未额外推定趋势阶段。|
|数据|旧接口的主机日期、逐股请求、缺失保留和来源单位均有风险。新接口使用北京时间及固定截止分钟。接口鉴权实测返回40101，盘中分钟可用性、成交额单位、财报字段、行情许可和清单完整性尚未通过生产验收。日线、当日流通股本与复权因子可能盘后才发布。|
 
当前没有多源冲突检查、全市场批处理性能实测、独立证券全量对账或可调参数文件。不得把成功解析或局部测试作为这些检查的证据。
